通用壓槍腳本（SidAllFPS）

FPS 後座力補償工具：自訂不同槍械的壓槍數據，隨時微調力道與間隔，協助把射擊手感調整到自己習慣的節奏。（正式名稱 All FPS；逐遊戲相容未公開，以 Releases 說明為準。）

版本 v1.2.0 C# WPF 正式版自訂槍械數據（9 組待原作確認） All FPS（逐遊戲未公開） 商業 · 試用＋購買
先下載試用版 zip 比較三種入口

v1.2.0：Fluent 深色／淺色主題、五大分頁、完整鍵盤導航；AHK 轉移至 C#（WPF）重寫，舊 AHK 設定檔實際沿用。

三種入口對照

正式版、試用版、購買授權是三種不同用途，不分優先順序：先看自己是哪種人，再點對應的按鈕。

正式版

正式版 zip

  • 適用對象：已有授權者。
  • 取得方式：GitHub Releases 下載 SidAllFPS-v1.2.0.zip。
  • 注意事項：解壓後以系統管理員身分執行 SidAllFPS.Wpf.exe；需 .NET 10 Desktop Runtime（x64）。

試用版

試用版 zip

  • 適用對象：首次評估者。
  • 取得方式：GitHub Releases 下載 SidAllFPS.Trial-v1.2.0.zip，14 天免費試用（伺服器核發票據，一機一張；僅限 3 組槍械預設）。
  • 注意事項：解壓後以系統管理員身分執行 SidAllFPS.Trial.exe；同樣需要 .NET 10 Desktop Runtime（x64）。

下載安全提示

若下載被封鎖，請點選「保留」；執行若遭阻擋，請點選「更多資訊」並按下「仍要執行」。（此為現行站原有的下載安全說明，與安全性保證無關。）

快速開始

三個步驟；先確認 .NET 環境，再談執行。

  1. 先檢查 .NET。確認已安裝 .NET 10 Desktop Runtime（x64）。
  2. 下載並解壓。下載對應的正式版或試用版 zip，解壓到本機資料夾（不要直接在壓縮檔內執行）。
  3. 以系統管理員身分執行。正式版執行 SidAllFPS.Wpf.exe，試用版執行 SidAllFPS.Trial.exe。
